# NexaBank Enterprise Network Project

## Overview
A complete enterprise network implementation for NexaBank PLC,
a mid-sized commercial bank in Dhaka, Bangladesh.
Designed to mirror real-world bank/telecom infrastructure.

## Organisation
- 3 Locations: Head Office (Motijheel), Branch 1 (Gulshan), Branch 2 (Uttara)
- 500 employees across all locations
- Regulated by Bangladesh Bank

## Technologies Used
- Cisco Packet Tracer 8.2.1
- GNS3
- draw.io
- Google Sheets
- GitHub
